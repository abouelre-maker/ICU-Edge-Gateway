# N-01 — Values between integer NEWS2 bands

**Status:** PROPOSAL — UNSIGNED. The interim rule was decided by Housam; the final policy is HD-E8, pending clinical review (HD-E4).

## Hazardous situation
The RCP 2017 tables are defined on integer values (and 0.1 °C for temperature).
Fractional inputs fell into whichever band the calculator's `<=` chain reached
first. RR = 8.5 scored 1 instead of the adjacent 3 — the reassuring direction.

## Change (risk control, proposed)
- `ScoringGate` checks each banded input against its recording grid (1 for RR, SpO2, SBP and HR; 0.1 for temperature).
- If the value lies between two grid points whose neighbours score differently, the more severe neighbour is passed to the calculator and `BETWEEN_BANDS_VALUE` is recorded, with the measured value.
- The neighbours are scored by `NEWS2Calculator`'s own band functions, SpO2 scale- and O2-aware. **No band boundary is restated or changed (R6).**
- The measured value is unchanged in `processed_vitals` and in FHIR output. Only the scoring input is adjusted.

## Residual / open
- This is the interim conservative rule. A clinical reviewer may replace it, for example with rounding to the recorded precision (HD-E8).

## Verification
- `tests/unit/test_n01_between_bands.py` (13 tests): eight gap cases across RR, HR, SBP, SpO2 and temperature; a Scale 2 on-O2 case; three fractions inside a single band are not flagged; the measured value is preserved.
- Full suite: 881 passed, 1 xfailed.
