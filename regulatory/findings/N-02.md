# N-02 — Preliminary results emitted as final

**Status:** PROPOSAL — UNSIGNED, pending clinical safety review (HD-E4).

## Hazardous situation
An OBX-11 `P` (preliminary) value was emitted in FHIR as `status: "final"`. A
downstream consumer could treat an unverified value, and any score derived
from it, as definitive.

## Change (risk control, proposed)
- Per-vital Observation.status follows OBX-11:
  - F → `final`;
  - P → `preliminary`;
  - C → `corrected`;
  - absent → `final` (historical behaviour; the absence is reported via `MISSING_RESULT_STATUS`, see A3).
- If any NEWS2 input is preliminary, the gate records `PRELIMINARY_RESULT` (informational; still scored) and the NEWS2 Observation status is `preliminary`.

## Open
- Absent OBX-11 → `final` is a conservative-for-compatibility choice, not a clinical one. A reviewer may prefer `unknown`. That would change many existing fixtures, whose status sits in OBX-10.
